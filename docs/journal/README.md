# Journal

One file per day: `YYYY-MM-DD.md`, append-only. Each entry:

```
## HH:MM - short title
- What I ran (command or Colab cell), where (Mac / Colab GPU type)
- Outcome (numbers, output paths)
- Errors and how they were fixed
```

End each phase with a `## Phase X report` entry: what was done, key numbers, what failed, what's next.
